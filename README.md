# spring-ai-in-action-samples
Examples from Spring AI in Action

This is the example code from Spring AI in Action. The main branch includes code as it appears in the book, built against Spring AI 1.0.3. The "spring-ai-1.1.0" branch includes the same examples, updated for Spring AI 1.1.0.

NOTE that due to a misstep on my part, I ended up creating two repositories for these examples. The front-matter of the book actually references both of those. (Oops!) This repository will continue to be updated as necessary to reflect any fixes, updates, and changes to Spring AI. The code in https://github.com/habuma/spring-ai-in-action-examples will remain as-is and not change any further.
